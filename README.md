# SignalLotto Bot

Telegram bot that auto-awards lottery entries to crypto traders when their devices report nearby radio-signal detections; winners are notified and payouts are recorded for manual owner fulfillment.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
